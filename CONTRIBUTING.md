# Contributing

This repository is public so that the project can be viewed, used, and tracked
while it is being developed. It is currently maintained as a solo project, and
contributions are not being accepted at this time.

Please do not open pull requests or feature issues for now. The project may
adopt a contribution process later as its design and API become more mature.

The MIT License still permits use, modification, and redistribution of the
software under its terms. This contribution policy only describes the current
maintainer workflow.
