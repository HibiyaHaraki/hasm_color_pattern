# Security Policy

This project is in early development and does not currently have a formal
security support or disclosure program.

Please do not report sensitive details in a public issue. If you discover a
security problem, contact the repository owner privately through the contact
options available on the hosting service. Include enough information to
reproduce the issue and avoid publicly disclosing it until it has been
reviewed.

There are currently no guaranteed supported versions. Security fixes, when
appropriate, will be handled as part of the project's ongoing development.
